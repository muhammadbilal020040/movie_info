## Objective

Design and develop a fully functional movie information website that displays movies with descriptions, categories, genres, and release dates, backed by a MySQL database and REST APIs.

## Project type

Individual full-stack web development project (not a group project).

## High-level features

- Public browsing of movies, categories, and genres
- Search by movie name, single category, and multiple genres
- Relevant results when no exact match is found
- Admin authentication and CRUD for movies, categories, and genres
- Poster images stored on the filesystem (paths only in the database)
